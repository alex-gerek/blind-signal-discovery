# WHISKER / BSD Expanded Synthetic Negative-Control Experiment (N_eval = 2,000)

**Scope:** Conditional evaluation of the three frozen nested calibrations (`120`, `200`, `220` windows from commit `6a43f08`, `seed = 2026`) on **2,000 brand-new independent `pink_colored` evaluation windows** (`8,000 s` = `2.222 hours`).
**Reproducibility:** Evaluation RNG stream = `make_split_rng(2026, 'neg_control_eval_2000_v1')`, strictly disjoint from calibration and prior evaluation streams. Zero thresholds tuned on evaluation data. Zero O3 holdout access.

## 1. Generator & Pipeline Independence Audit

- **Noise generator (`src/bsd/noise.py:generate_pink_colored`):** Each 4-second window (`4096` samples at `1024 Hz`) is generated by an independent call drawing a fresh spectral slope `alpha ~ Uniform(0.85, 1.15)` and fresh Gaussian white FFT bins, shaped via per-window `rfft/irfft` and RMS-normalized independently to `sigma = 1.0`. **No filter state, normalization, or memory carries across windows.**
- **Frozen Raw Detector (`MultiResolutionDetector.analyze`):** Strictly stateless per window; therefore, binary false-alarm indicators `I(score_i > threshold)` across the `2,000` evaluation windows satisfy the i.i.d. Bernoulli assumption of the 95% Wilson score interval (conditional on the frozen threshold).
- **Adaptive Workstation Pipeline (`AdaptiveRegimeManagerV2b`):** Uses rolling `12`-window continuum and glitch-storm monitors plus finite-state recalibration. Its window-level decisions can exhibit serial dependence across adjacent windows; accordingly, raw frozen outcomes and adaptive outcomes are reported strictly separately.
- **False-Alarm Definition:** For a single non-overlapping 4-second pure-noise window, a false alarm occurs when `stft_max_score > active_threshold` (strict inequality, `enable_glitch_veto=False`, `enable_line_veto=False`).

## 3. Paired Comparison & Non-Nesting Audit Across the Same 2,000 Windows (Frozen Raw Detector)

All counts below are verified directly against `paired_false_alarms.csv` (`56` rows; `120w = 50`, `200w = 30`, `220w = 31`):

- **False alarm under ALL THREE calibrations (`120w & 200w & 220w`):** `25` windows
- **False alarm under ANY calibration (`120w | 200w | 220w`):** `56` / `2000` windows (`1944` clean under all three)
- **Exclusive single-condition false alarms:** `only_120 = 21`, `only_200 = 0`, `only_220 = 5`
- **Pairwise-only overlaps:** `120&200 only = 4`, `120&220 only = 0`, `200&220 only = 1`
- **Discordant pairs `(A only, B only)`:** `120 vs 200 = (21, 1)`, `120 vs 220 = (25, 6)`, `200 vs 220 = (4, 5)`

### Why the Paired False-Alarm Sets Are Not Nested
Even though the scalar thresholds are strictly ordered (`2.2568 < 2.3089 < 2.4250`), the three false-alarm sets are **not nested** (`only_220 = 5`, `120&200 only = 4`, `200&220 only = 1`). Detector configuration (`DEFAULT_V02_SCALES`), raw per-scale STFT scores, and decision logic (`max_global_score > global_threshold`) are identical across conditions, **but each condition uses a different Split-A per-scale standardization (`median` and `spread_scale = Q95 - median`):**
- `short_31ms` spread: `33.67` (`120w`) -> `30.60` (`200w`) -> `31.39` (`220w`)
- `medium_125ms` spread: `12.07` (`120w`) -> `14.20` (`200w`) -> `17.64` (`220w`)
- `long_500ms` spread: `19.86` (`120w`) -> `18.03` (`200w`) -> `17.43` (`220w`)

Because the same raw 3-scale STFT vector maps to **different standardized `max_global_score` values** under each condition:
- **Example `only_220` (Window `71`):** `score_120 = 2.1071` (`False`), `score_200 = 2.3091` (`False`), `score_220 = 2.3879 > 2.3089` (`True`) — a `long_500ms`-dominated window whose standardized score rose as `long_500ms` spread shrank (`19.86 -> 17.43`).
- **Example `120&200 only` (Window `1008`):** `score_120 = 3.0499` (`True`), `score_200 = 2.4884` (`True`), `score_220 = 2.0572 < 2.3089` (`False`) — a `medium_125ms`-dominated window whose standardized score shrank as `medium_125ms` spread grew (`12.07 -> 17.64`).

## 4. Statistical Interpretation, Adaptive Metrics & Explicit Scope Limitations

- **Observed rates vs. true rates & Wilson CI limits:** The reported values (`2.50%`, `1.50%`, `1.55%`) are **observed false-alarm rates** on this 2,000-window evaluation set, not exact true population rates. The 95% Wilson score interval assumes i.i.d. Bernoulli trials with constant probability `p` conditional on the fixed threshold; it is an asymptotic normal-approximation interval (coverage can deviate slightly near `p -> 0`) and captures **only** evaluation sample uncertainty (`N_eval = 2,000`), not calibration-threshold uncertainty across random calibration seeds.
- **Generator-based independence vs. Ljung–Box diagnostics:** The i.i.d. assumption for `Frozen Raw Detector` rests strictly on the **generator design** (`generate_pink_colored` draws each window independently with no carried filter/normalization state) and the stateless raw detector. The non-significant Ljung–Box p-values (`0.114`, `0.071`, `0.087`) check only linear lag-1..10 autocorrelation of scalar scores; failing to reject `H_0` is **not** proof of statistical independence (nonlinear or higher-order dependence is not ruled out by Ljung–Box).
- **Specificity of the `50 -> 30 / 31` reduction:** The observed drop from `50/2000` (`120w`) to `30/2000` (`200w`) and `31/2000` (`220w`) is specific to these three frozen calibrations (`seed = 2026`) and this synthetic `pink_colored` evaluation set. It does **not** imply that increasing calibration size generally reduces realized FAR on every seed (larger calibration reduces threshold variance around target FAP, rather than monotonically lowering FAR). These conditional results do not generalize to the full calibration procedure or to real nonstationary detector data; a separate multi-seed study is required for procedure-level inference.
- **Adaptive full vs. clean metrics:** `Adaptive Full` uses numerator = all post-veto nominated windows (`50`, `30`, `31`) and denominator = all `2,000` windows (`n_regimes = 1`, `veto_config = None`, so counts match `Frozen Raw`). `Adaptive Clean` uses numerator = post-veto nominated windows among eligible windows (`50`, `30`, `31`) and denominator = eligible clean-calibrated windows (`1985`, `1989`, `1979`, excluding `15`, `11`, and `21` windows flagged by the rolling 12-window continuum/glitch monitors; excluded windows are never counted as true negatives). Because the 12-window Stream B monitors introduce serial dependence into window eligibility (`N_clean` is random and clustered), adaptive clean FAR is conditional on surviving eligibility and any i.i.d. Wilson CI on adaptive outputs is only approximate.
