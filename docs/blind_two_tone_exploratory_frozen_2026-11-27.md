## Four arms and fixed decision rules

W0: historical three-scale bank with longest Hann 512 samples/overlap384. W1: keep short/medium unchanged, replace longest by Hann1024/overlap896. Sample rate1024, record4s; longest hop128samples=.125s. Frequency/time median kernels21/7, seed Z>4,min cluster2,eight-connectivity unchanged. W1 frequency smoothing footprint changes because bin spacing changes: this is a configuration contrast, not an isolated window-duration causal test.

D0: two accepted longest-scale candidates with strictly disjoint frequency boxes and overlapping time boxes. Their peak frequencies and peak normalized Z values define the proposal. D1: all D0 proposals plus two strict local maxima within one accepted longest-scale cluster's frequency extent. For that cluster average full Z over its occupied time columns, find peaks across the full frequency axis, retain only peaks in its extent; heights>=4, at least one interior bin, interior valley<=0.8*smaller peak. No truth frequencies, time crop or source count enters inference. All pairs score=min(two peak heights); choose maximum score, tie by sorted frequency pair then onset. Retain proposal list including duplicates removed by exact frequency-pair identity, retaining strongest then earliest. Exact duplicate frequency estimates are invalid, never counted as two. There is no interpolation. If no pair exists, score=-infinity and no claim. There is at most one returned pair per arm/observation. D0/D1 do not change anomaly decisions or production clusters.

Anomaly acceptance follows independent per-W calibration, target FAP.005,284noise observations,85A/199B. Standardize (raw-median)/max(Q95-median,1), strict greater than frozen global maximum threshold. All scales contribute to the anomaly threshold, but pair proposals use only longest-scale accepted components.

Separately calibrate each W/D full-observation pair maximum on199noise and199one-tone records. Per group alpha.01 uses strict exceedance of order ceil((199+1)*.99)=198; take larger group cutoff. A -infinity cutoff is explicitly allowed when that order contains only missing proposals: any finite eligible proposal can then claim, but missing proposals never claim. Store missing scores/cutoffs as JSON null plus explicit semantics, not unavailable calibration. Equivalent per-group empirical p=(1+count(null>=score))/200; require both p<=.01 and score>combined cutoff. This is marginal calibration for the declared null populations, not per-frequency or real-sensor certification. No held-out tuning, best-arm selection or post-hoc threshold changes.
