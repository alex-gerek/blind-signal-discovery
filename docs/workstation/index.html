Blind Signal Discovery (BSD) — Browser Workstation

Browser Interactive Demo (v0.3.0): Runs template-free STFT excess-power whitening, 8-connected clustering, and exact finite-sample conformal calibration (p_emp = (1 + n_ge) / (N_cal + 1) ≤ target_fap) directly in your browser — no installation required. For the full 3-scale Python core (author-reported 87/87 tests at 986dd46), run app/bsd_workstation.py locally. Statistical anomalies are never proof of a physical discovery. Open limitations: WAV aliasing, dropped nonfinite CSV rows, unverified background separation, abstention-summary denominators, and incomplete export provenance. Use synthetic demonstrations while these file-measurement issues are reviewed. See known limitations.
Run a measurement to view calibration status.

Scientific Output Semantics

  • Measured features: 1D time-domain waveform and Hann-windowed STFT excess power normalized by 2D spectral/temporal medians.
  • Statistical anomalies: Windows whose maximum connected-cluster excess-power score strictly exceeds the exact conformal threshold (score > threshold) when detection_available = true.
  • Abstention on unattainable FAP: When 1 / (N_cal + 1) > target_fap, threshold is null (CALIBRATION_UNAVAILABLE), detection_available = false, and active_mode_anomaly_flag = false.
  • Physical confirmation: NOT_ESTABLISHED_BY_SINGLE_CHANNEL_WORKSTATION.
