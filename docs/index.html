Blind Signal Discovery (BSD)

Finding unknown structure in noisy time series, with a false-alarm rate you can measure.

Open the Workstation (Browser) GitHub Repository Zenodo DOI
Scientific Scope: BSD is a methodological research prototype on synthetic and user-supplied time-series data. It distinguishes measured features, statistical anomalies, and detection candidates, and never classifies a single-channel anomaly as an independently confirmed physical discovery.

What this prototype tests

The table describes the Python research core. The browser demo is a separate single-scale implementation. Before interpreting file measurements, read the known limitations; documentation corrections do not rerun historical studies.

WhiteningWhat rises above the local spectral and temporal floor?Median DC removal, unpadded STFT, 2D robust median-filter background normalization

Why we built this (and related projects)

This repository is the mathematical and statistical testing ground first. Once the template-free detection math, conformal calibration bounds, and failure modes are verified on strict synthetic controls and real time-series benchmarks, we aim to explore whether these same tools can inform our acoustic and musical research projects: Periodic Table of Sound and PHARMAKON.
